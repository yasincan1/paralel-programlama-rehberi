# Paralel Lab

Paralel Programlama dersi için Türkçe, etkileşimli sınav çalışma rehberi.

- 18 konu anlatımı ve çözümlü sınav soruları
- Süreç durumları, semafor, yarış durumu, paralellik ve dizi toplama animasyonları
- Ders tamamlama, okuma konumu, tema ve yazı boyutu kaydı
- İlerleme yedeği indirme ve geri yükleme

Site tek başına çalışan `index.html` dosyasıdır; derleme veya sunucu uygulaması gerektirmez. `.nojekyll` dosyası statik yayın için eklenmiştir.

Çalışma ilerlemesi kullanıcının tarayıcısında saklanır; GitHub hesabına gönderilmez ve cihazlar arasında otomatik eşitlenmez. Yerel dosyadan canlı siteye geçerken eski ilerleme, uygulamadaki **Yedeği indir / Yedekten yükle** kontrolleriyle taşınabilir.

Ham ders fotoğrafları bu yayın klasörüne dahil edilmemiştir.
